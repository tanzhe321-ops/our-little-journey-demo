# Our Little Journey · Online Demo / 在线试玩

**[Play Demo / 点击试玩](https://tanzhe321-ops.github.io/our-little-journey-demo/)**

A cozy capybara love story across China, America and Europe. This repository contains the built static game, published with GitHub Pages. No ChatGPT login or service is needed to play. Open the link on a phone or computer and tap **Begin our story** to start with music.

一个跨越中国、美国和欧洲的卡皮巴拉恋爱故事。本仓库保存构建后的静态游戏，由 GitHub Pages 托管。试玩无需 ChatGPT 账号或服务，电脑和手机都能打开。点击 **Begin our story** 开始游戏与音乐。

Desktop: WASD / arrow keys. Mobile: hold the on-screen direction buttons; landscape recommended. Music can be muted.

电脑：WASD / 方向键。手机：长按屏幕方向按钮，建议横屏。背景音乐可以静音。

Source code is maintained separately in the creator’s private repository. Personal photographs, supplied music recordings and reference images are part of the original experience; their inclusion does not grant redistribution rights.

源码在创作者的私有仓库中单独维护。个人照片、提供的音乐录音和参考图片用于保留原始体验，收录不代表授予再分发权。
